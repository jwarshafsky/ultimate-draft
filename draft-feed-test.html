ESPN Draft Feed Test

Standalone check — does ESPN's mDraftDetail feed stream picks live during an in-progress draft? This talks only to the proxy; it touches nothing in Ultimate Draft.

Connection

Two tests. REST polling hits the old post-draft endpoint (proven not-live). SOCKET capture connects the proxy to ESPN's real-time draft websocket and dumps raw frames — the one that should catch live picks. Most reliable: in your live draft tab, open DevTools → Network → filter "WS" → click the JOIN connection → right-click → Copy URL, and paste it above. Then hit Start SOCKET capture.
